# AdTech Attribution & Funnel Analytics — Member 1 Handoff

This package contains the Member 1 Node.js event-ingestion backend and database exports.

## Contents

- `src/server.js` — Express API and event synchronization endpoints
- `src/db.js` — PostgreSQL and MongoDB connections
- `database/schema.sql` — PostgreSQL schema, constraints, and indexes
- `database/sample_data.sql` — sample PostgreSQL records and attribution results
- `.env.example` — environment-variable template (copy to `.env` and fill in local credentials)
- `package.json` / `package-lock.json` — Node dependencies

## Requirements

- Node.js and npm
- PostgreSQL
- MongoDB running locally or a reachable MongoDB instance

## Setup

1. Create a PostgreSQL database named `adtech_analytics`.
2. Restore the schema first, then the sample data. From this package directory, for example:

   ```powershell
   psql -U postgres -h localhost -p 5432 -d adtech_analytics -f database/schema.sql
   psql -U postgres -h localhost -p 5432 -d adtech_analytics -f database/sample_data.sql
   ```

3. Copy `.env.example` to `.env` and update the PostgreSQL password and any connection settings. Do not commit or share `.env`.
4. Install dependencies and start the server:

   ```powershell
   npm install
   npm start
   ```

5. The API runs on port `3000` by default. Check `GET http://localhost:3000/`.

## API endpoints

- `GET /` — API status
- `POST /api/events` — receive an event and store it in MongoDB
- `POST /api/events/sync` — synchronize MongoDB events into PostgreSQL

Supported event types: `IMPRESSION`, `CLICK`, `VISIT`, `ADD_TO_CART`, and `PURCHASE`.

## Important implementation note

The current backend syncs purchase events into the PostgreSQL `conversion` table. Attribution rows for newly synced purchases were calculated separately using SQL in the current demo workflow; attribution is not automatically generated by the sync endpoint yet.

## Sharing safely

Do not include `.env`, passwords, `node_modules`, or private credentials when sharing this package. The sample data contains demo email addresses; keep it within the project team or anonymize it before making the repository public.
